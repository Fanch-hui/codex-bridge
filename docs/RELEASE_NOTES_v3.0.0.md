# Codex Bridge v3.0.0

## 更新内容

- 全新工作台支持直接进行模型对话、使用工具和技能，并管理模型连接、上下文窗口及自动压缩阈值。ChatGPT 账号与多个自定义 API 可同时使用，各会话独立保存模型和推理强度。
- 工作台支持委派外部 Agent、查看执行进度与结果；具备隔离能力的子任务可在独立工作副本中执行，并在合并时处理文件冲突。
- 网页工作台支持单窗口最多四格会话，每格可独立查看实时对话和发送输入；同一项目可配置同时运行的 Agent 数量。
- 新增 Claude Code 接入，支持连接、执行任务、审批与继续会话；改进 OpenCode、DeepSeek Harness、Qoder 等 Agent 的连接与模型选择。
- 工作台新增 ZCode 和 WorkBuddy 模型连接，完善模型目录刷新、启动恢复及后台任务状态反馈。
- 新增默认工作区，新建对话和未指定项目的 MCP 操作可直接使用；项目与会话在侧栏按工作区组织。
- 优化桌面和后台服务的启动、刷新与资源占用；可在设置中关闭工作台，收起内置浏览器时释放页面资源。
- 修复 Windows 文件替换可能导致服务崩溃的问题，并改进任务恢复、审批和连接稳定性。

## 使用提示

- 更新后请在 ChatGPT 插件设置中刷新 Codex Bridge。
- macOS 安装包使用 ad-hoc 签名。若系统阻止打开，请在“系统设置 → 隐私与安全性”中允许此次打开。
- Linux 使用系统包管理器安装对应架构的 `.deb`；1.3.5 版本首次升级需手动下载安装包。
