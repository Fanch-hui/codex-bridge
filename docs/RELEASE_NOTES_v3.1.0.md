# Codex Bridge v3.1.0

## 更新内容

- 可以把供应商模型接入本机其他 Agent。Codex CLI、Codex 桌面版、Claude Code 和 Claude 桌面版分别提供配置入口；Codex CLI 与 Claude Code 可选择保留官方登录态。
- 工作台分屏支持并排查看内置会话、子 Agent 和外部 Agent。点击「+」创建内置会话，点击旁边的下拉按钮选择外部 Agent。网页工作台专注于网页客户端任务，仍可续写、审批或将会话带到工作台。
- 社区供应商的模型可以在工作台中直接使用；改进插件安装提示、模型列表刷新和模型网关的参数兼容性。
- 修复任务启动与取消同时发生时的状态错误。排队任务启动失败时保留具体原因；服务重启后，不再把尚未启动的子任务留在无法处理的审批状态。
- 改进首次写入 Agent 配置后的恢复；修复从项目或动态页打开网页任务时进入错误工作台的问题。Windows 客户端发送本机请求前会核验后台服务身份。

## 使用提示

- 要让本机 Agent 使用供应商模型，先连接供应商，再到「已接入应用 → 连接应用」选择目标应用和允许使用的模型。仅接入模型时，无需开启 MCP 项目权限。
- 使用 ChatGPT 插件的用户，升级后请在插件设置中刷新 Codex Bridge。
- macOS 安装包使用 ad-hoc 签名。若系统阻止打开，请前往「系统设置 → 隐私与安全性」允许此次打开。Linux 用户请选择与架构对应的 `.deb` 安装包。
