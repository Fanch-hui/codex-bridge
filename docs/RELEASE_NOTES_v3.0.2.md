# Codex Bridge v3.0.2

## 更新内容

- 新增消息信箱，可在侧栏状态指示灯旁查看开发者通知和未读提醒。
- 新增私密反馈，支持发送文字和截图、查看处理状态及开发者回复。
- 通知支持按平台和应用版本推送，并提供更新或网页入口。
- 信箱刷新保留阅读位置、输入焦点和反馈草稿；提交失败后可继续重试。

## 使用提示

- 更新后点击侧栏状态指示灯旁的信箱图标，即可查看通知或提交反馈。
- 反馈仅发送主动填写的内容和选择的截图；请勿上传密码、密钥等敏感信息。
- v1.1.2 用户需从发布页面下载对应安装包，手动覆盖安装一次，以更新旧仓库地址。
- 更新后请在 ChatGPT 插件设置中刷新 Codex Bridge。
- macOS 安装包使用 ad-hoc 签名。若系统阻止打开，请在“系统设置 → 隐私与安全性”中允许此次打开。
- Linux 使用系统包管理器安装对应架构的 `.deb`；1.3.5 版本首次升级需手动下载安装包。
