# Codex Bridge v3.2.0

## 更新内容

- 工作台新增联网搜索：在工作台「设置」中选择 Brave Search、Tavily 或自定义搜索地址（支持 SearXNG JSON 及 Brave/Tavily 兼容接口），验证成功后模型即可联网搜索。密钥保存在系统凭据存储中，未配置时不提供搜索。
- 工作台新增「团队协作」：在主会话输入器中按会话开启或关闭，开启后检查器「协作」页显示团队任务看板。
- 工作台引擎升级，并使用 Codex Bridge 自己的身份与系统提示词，任务完成、权限请求和最终回答更清晰；界面中统一使用「工作台」称呼。
- 工作台的原生子 Agent 共享项目目录写入，数量遵循引擎自身上限，不再占用「同一项目同时运行的 Agent」名额；该名额现在只计算已连接的外部 Agent。
- 外部 Agent 只能由工作台主会话调用，避免子 Agent 在你不知情时消耗你自己的账号额度。
- 修复外部子 Agent 在隔离副本、状态显示和中断恢复方面的问题。

## 使用提示

- 使用联网搜索前，请到工作台「设置 → 联网搜索」选择服务并填写地址或密钥；自定义地址需使用 HTTPS 或本机回环地址。
- 使用 ChatGPT 插件的用户，升级后请在插件设置中刷新 Codex Bridge。
- macOS 安装包使用 ad-hoc 签名。若系统阻止打开，请前往「系统设置 → 隐私与安全性」允许此次打开。Linux 用户请选择与架构对应的 `.deb` 安装包。
