# Codex Bridge v3.1.1

## 更新内容

- 新增技能中心：在「设置 → 技能与扩展」集中管理本机各 Agent 的技能。自动发现 Codex、Claude Code、OpenCode、Gemini、Pi、Qoder 等的技能目录，合并重复技能，同名冲突可指定首选、对比差异或另存一份；导入、改名和删除只作用于 Bridge 自己的技能库，不改动其他 Agent 的目录。
- 社区供应商内置「Antigravity（本机 agy）」插件，使用本机已安装并登录的 agy 接入其模型，不会自动下载或更新 agy。
- 社区供应商模型支持选择推理强度：工作台输入器只显示模型实际支持的档位；接入 Pi 和 OpenCode 时同样写入可选强度。
- 工作台模型选择器显示较小的上下文窗口，跟随模型上限压缩时给出提示；ChatGPT 模型按实际容量计算上下文。接入本机其他 Agent 时传递已知的上下文与输出上限，模型列表按供应商分组。
- 工作台启动更快；输入器的选择器不再遮挡发送按钮；ChatGPT 登录过期时给出提示；提问卡片改为更清晰的样式。

## 使用提示

- 使用 Antigravity 插件前，先在「连接」中连接本机 Antigravity，再到社区供应商中安装或更新该插件。
- 已接入 Pi 或 OpenCode 的用户，在「已接入应用」重新连接一次即可获得推理强度选项。
- 使用 ChatGPT 插件的用户，升级后请在插件设置中刷新 Codex Bridge。
- macOS 安装包使用 ad-hoc 签名。若系统阻止打开，请前往「系统设置 → 隐私与安全性」允许此次打开。Linux 用户请选择与架构对应的 `.deb` 安装包。
