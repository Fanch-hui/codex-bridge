# Agent 一键配置

已有本机安装会自动发现，点击“连接”即可沿用原有流程。在“连接 → 本机 Agent 引擎连接”中，OpenCode、DeepSeek Harness、Antigravity、Pi 和 Qoder 均提供“一键配置”。Codex 使用独立的执行引擎连接。

1. Qoder 先选择中国版或国际版，再点击“一键配置”。其他 Agent 直接点击。
2. Bridge 检查已有安装并准备运行依赖。发现多个可用安装时，选择本次使用的安装；缺少程序时，从官方来源安装当前官方版本。
3. 按弹窗完成登录或配置。OpenCode、Pi、Qoder 和 AGY 的“打开登录 / 配置”会打开原生终端；DSH 在弹窗中填写服务地址和 API Key。
4. 完成后点击“我已完成，重新检测”。连接成功后，在设置中选择模型，再提交任务。

AGY 连接需要明确允许将当前用户的全局 Tool Permission 设置为 Always Proceed。该设置也影响使用同一配置的其他 AGY CLI 任务。

## 安装位置

默认安装在 Bridge 服务数据目录的 `AgentTools` 下，按 Agent 和 Qoder 地区分别管理。安装不需要管理员权限，也不要求修改全局 PATH。缺少兼容的 Node/npm 时，Bridge 会准备独立运行时。

需要换盘或使用特定目录时，先展开该 Agent 的“高级安装选项”，填写当前用户可写的绝对路径。已有兼容安装优先复用；该选项用于放置需要新增的程序和依赖。

Qoder 的 CLI、SDK 和登录态按地区使用。Bridge 通过接口与模型目录验证后，才切换该地区的活动安装和运行路径。

## 中断与重试

- 安装期间可以查看进度或取消。再次配置会复用已完成且验证通过的安装。
- 关闭连接页后安装继续运行；重新打开页面可查看当前状态。服务退出会中断正在执行的安装，重启后可以重新开始；等待登录的操作可以继续。
- 下载、权限或磁盘错误会显示在配置进度中。修正网络、代理、目录权限或可用空间后重试。
- 原生终端无法打开时，Bridge 会尝试复制受控登录命令，也可打开官方登录说明。
- 登录过期或模型目录为空时，完成原生登录或服务商配置后重新检测。接口和模型目录验证不代表订阅额度或实际任务一定可用。
- DSH 凭据与 AGY 全局权限修改需要该 Agent 的任务先结束。
- Qoder 官方目前不提供 Windows ARM64 运行时，该平台会提示使用受支持的平台。

手动安装、外部 Profile 和按路径登记仍可在高级选项中使用。登录材料通过对应 Agent 的原生流程处理；DSH 的 API Key 保存到系统凭据存储，提交或关闭编辑器后清空输入。
