# Codex Bridge v2.0.0

## 更新内容

- 新增 DSH 开发台（beta），提供持续会话、项目文件编辑、Git 变更查看和图片输入；侧栏与文件预览可独立收起。
- DSH 开发台在对话区选择模型和推理强度，引擎设置提供模型目录与刷新；ACP 会话使用完整权限。
- DSH ACP 与原生桌面使用独立连接、模型设置和会话入口，原生桌面会话在协作工作台中继续使用。
- 各 Agent 的长正文、工具输出和大批量进度采用有界展示与分页，保留工具状态、审批和完成结果，任务持续执行。
- 修复 Codex 命令执行和文件搜索进度完成时的校验错误，改善任务失败诊断。
- 修复首页 DSH 桌面版连接状态展示，按原生桌面的实际连接状态提供提示。

## 使用提醒

- DSH 开发台仍处于 beta 阶段，ACP 会话使用完整权限，请选择已授权的项目目录。
- DSH 原生桌面接入支持 macOS 与 Windows x64；安装或更新 Connector 前，请完全退出 DSH 桌面版。
- **更新后请在 ChatGPT 插件设置中刷新 Codex Bridge。**
