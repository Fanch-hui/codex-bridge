# Codex Bridge v3.3.0

## 更新内容

- Codex 桌面版支持官方模型与 Bridge 网关模型共存：在「连接」中接入 Codex 桌面版后，模型列表同时显示官方模型和你在 Bridge 中启用的社区与自定义 API 模型（含 Anthropic 与 Chat 兼容接口），可在同一个 Codex 里随时切换。
- 官方模型继续走 Codex 原生的 WebSocket 连接，响应速度与直连一致；Windows 版也已支持。网关模型的响应延迟更低，并按需加载已连接应用的工具。
- 动态与用量摘要显示网关模型名称，并按模型统计官方 Codex 的用量与缓存命中。
- 内置 OpenCode Zen 免费模型的社区供应商插件，启用后可直接在工作台和模型网关中使用。
- 修复撤销 Codex 共存连接后，Codex 配置中的默认模型没有恢复、`model_provider` 丢失的问题。
- 修复 Codex 桌面版接管时模型列表不完整、撤销配置卡住的问题。

## 使用提示

- 若此前撤销共存连接后手动改过 Codex 的 `config.toml`，无需再改；新版撤销会自动恢复原来的默认模型。
- 使用 ChatGPT 插件的用户，升级后请在插件设置中刷新 Codex Bridge。
- macOS 安装包使用 ad-hoc 签名。若系统阻止打开，请前往「系统设置 → 隐私与安全性」允许此次打开。Linux 用户请选择与架构对应的 `.deb` 安装包。
