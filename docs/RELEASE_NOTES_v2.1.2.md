# Codex Bridge v2.1.2

## 更新内容

- 主导航整理为概览、连接、项目和工作台，设置固定在侧栏底部；概览集中展示连接状态、待处理事项和最近会话。
- Agent 的连接、默认模型和任务权限集中到连接详情，Gemini 按网页版与同机客户端分别配置；诊断与日志统一从设置进入。
- 工作台整合会话操作与历史入口，内置聊天浏览器按需展开并记住选择；DSH 开发台使用文件与变更标签，保留编辑草稿。
- 改善 Qoder 主结果与后台任务的完成处理，缩短新会话初始化路径，保持历史会话的账号核对。
- 完善共享模型目录查询的取消、缓存和失效处理；Codex 交接沿用普通任务的模型选择规则，并检查准备后的配置变化。
- 更新原生渠道适配，修复已有安装选择与项目操作校验，改善模型设置和页面刷新的一致性。

## 使用提示

- 更新后请在 ChatGPT 插件设置中刷新 Codex Bridge。
- 修改 Agent 默认模型与权限，请进入“连接”并打开对应 Agent；DSH ACP 配置位于工作台的 DSH 开发台。
- 本次升级沿用已有项目、配置、会话记录及内置浏览器登录状态。
