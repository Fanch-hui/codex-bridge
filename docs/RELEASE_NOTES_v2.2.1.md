# Codex Bridge v2.2.1

## 更新内容

- DSH 桌面连接详情新增连接器更新提示和“更新连接器”按钮，高级配置提供重新安装入口。
- 适配 DSH Desktop 0.2.1-rc.3 的会话标题和工具结果事件，保持历史会话名称与工具完成状态正确显示。
- 增加聊天附件导入和项目文件下载，支持二进制文件传输与文件传输面板。
- 改善 Tunnel 连接中断后的恢复和连接诊断，减少连接停滞对远程操作的影响。

## 使用提示

- 更新后请在 ChatGPT 插件设置中刷新 Codex Bridge。
- 使用 DSH 桌面时，先完全退出 DSH，再到“连接 → DSH 桌面”更新连接器；完成后打开并连接 DSH。
- 本次升级沿用已有项目、配置、配对、会话记录及内置浏览器登录状态。
