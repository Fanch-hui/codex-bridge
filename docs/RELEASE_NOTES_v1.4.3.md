# Codex Bridge v1.4.3

## 更新内容

- 重构桌面六个页面的布局与信息层级，以背景和留白分组；连接和设置的复杂配置进入二级页面。
- 设置页直接显示 Agent 连接状态、模型、推理强度和任务权限；页首刷新重新获取已连接引擎的模型目录及默认设置。
- 修复模型错误误标和恢复后的旧提示残留，以及连接操作失败后的重试、Qoder 配置保存和官方文档入口。
- 日志诊断就地展开，刷新时保留行按钮与键盘焦点；工作台保留输入草稿、输入法、审批和浏览器分栏行为。
- 增加 Direct 命令规则预检和会话历史筛选，改进任务启动失败诊断及更新取消、等待空闲反馈。

## 使用提醒

- 模型与默认权限位于“设置”，安装、连接与配对位于“连接”；未连接的 Agent 仍可预先配置默认权限。
- **更新后请在 ChatGPT 插件设置中刷新 Codex Bridge。**
