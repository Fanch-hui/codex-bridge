# Codex Bridge v2.2.2

## 更新内容

- 改进 DSH 桌面连接器安装与更新：检查并启用连接器，保留现有包存储配置，并在安装失败时显示诊断代码。
- DSH 运行与一键配置按已安装版本的要求选择 Node；改善 Qoder 暂时不可用时的重新连接。
- 改进 OpenCode 连接：一键配置直接检测可用模型，并识别新版 OpenCode；常见模型服务配置可供后台执行使用。
- Tunnel 组件更新至 0.0.18，ChatGPT 和 Dot 单次任务等待调整为最多 90 秒；等待结束后任务继续运行，可再次等待或查询结果。
- 优化桌面页面、窄窗口工作台布局和键盘焦点，记住侧栏收起状态；macOS 新增主导航及设置快捷键。

## 使用提示

- 更新后请在 ChatGPT 插件设置中刷新 Codex Bridge。
- 更新 DSH 桌面连接器前，请完全退出 DSH 桌面；完成后重新打开并连接。
- OpenCode 免费模型、本地服务及已配置接口可直接连接；需要授权时按所选服务要求配置。OpenCode 2.x 的原生账号与 Bridge 项目数据库分别管理。
