# Codex Bridge v1.4.5

## 更新内容

- 修复 macOS 与 Windows 连接 DSH 桌面版时，运行工件数量超过上限导致注册失败的问题。
- DSH ACP 与 DSH 桌面分为两个独立连接，模型和默认设置分别保存；已有任务保留原连接。
- 优化 DSH 桌面流程：发现安装后先安装连接器，再连接配对；确认后自动显示已连接。
- 修复 Codex 启动时模型目录暂时不可用后需要手动刷新的问题，持续失败保留具体诊断。
- 修复首次模型加载失败时默认设置丢失、旧刷新覆盖已保存设置的问题。
- 改善系统凭据授权与 Agent 重连失败提示。

## 使用提醒

- 安装或更新 DSH Connector 前，请完全退出 DSH 桌面版。
- 更新后如系统请求钥匙串授权，请完成授权，再重新检测连接或刷新模型。
- **更新后请在 ChatGPT 插件设置中刷新 Codex Bridge。**
