# Codex Bridge v3.0.3

## 更新内容

- 网页工作台分屏支持独立编写和发送任务草稿，标签页、新建任务与会话切换跟随当前分屏。
- 改进工作台子 Agent 的并行准备、隔离结果合并、停止与恢复，支持将委派任务限定为只读。
- 修复 macOS 上 Gemini 本地 MCP 的服务连接，新增本地接入检测与结果展示。
- 修复工作台重试、续写、消息回执及模型目录刷新的状态处理，保留失败后的输入与既有模型选择。
- 更新工作台内置引擎，修复消息信箱资源加载，并更新使用指南与界面截图。

## 使用提示

- 更新后请在 ChatGPT 插件设置中刷新 Codex Bridge。
- 使用 Gemini 本地 MCP 时，请重启 Bridge 后台服务，并在「连接 → Gemini」重新检测接入状态。
- v1.1.2 用户需从发布页面下载对应安装包，手动覆盖安装一次，以更新旧仓库地址。
- macOS 安装包使用 ad-hoc 签名。若系统阻止打开，请在“系统设置 → 隐私与安全性”中允许此次打开。
- Linux 使用系统包管理器安装对应架构的 `.deb`；1.3.5 版本首次升级需手动下载安装包。
