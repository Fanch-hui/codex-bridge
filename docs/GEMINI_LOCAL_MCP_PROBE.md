# Gemini 本地 MCP 沙盒探针

本探针用于验证 Gemini 启动的 MCP 子进程能否读取指定的合成测试文件、访问本机回环 HTTP，为本地连接器的配对实现提供实际依据。

探针在连接时自动检查，提供实时复查工具 `local_mcp_probe` 和连接结果工具 `probe_status_file_<状态>_loopback_<状态>`。连接结果直接体现在工具名称中，查看关联应用的工具列表即可读取。它不连接 Bridge 后台服务，不使用 XPC，不读取凭据、项目或数据库，也不提供文件与命令工具。普通 `--mcp-stdio` 入口保持原有行为。

## 1. 准备测试

使用包含 `--mcp-stdio-probe` 入口的本次构建产物。可执行文件位于 App 内的 `Contents/MacOS/CodexBridge`；不要只填写 App 文件夹路径。

在源码仓库根目录打开终端，执行：

```bash
python3 Scripts/prepare-gemini-local-probe.py \
  --executable "/包含本次构建的/CodexBridge.app/Contents/MacOS/CodexBridge" \
  --directory "$PWD/.build/gemini-local-probe-marker"
```

`--directory` 必须是尚不存在的专用叶子目录，且父目录已经存在。准备脚本创建的文件名为 `marker.txt`，内容是固定的公开标记，不含密钥。脚本只监听 `127.0.0.1`，打印实际端口及可直接粘贴的完整 MCP 启动命令。

**保持该终端运行**。按 Ctrl-C 可停止本次 HTTP 服务；脚本保留测试文件，不删除已有目录。再次准备测试时选择另一个新目录。

## 2. 在 Gemini 手动运行

1. 添加自定义关联应用，选择「本地 MCP」，名称填写 `Codex Bridge 本地诊断`。
2. 将脚本打印的完整启动命令粘贴到「命令」栏。
3. 先记录默认沙盒设置并尝试连接。若文件或网络被拒绝，再按 Gemini 实际提供的设置，只允许读取本次测试目录及访问本机回环网络。不要授予整个 Bridge 服务目录或主目录。
4. 完成连接后，直接查看关联应用详情的「应用内操作」。两项通过时会列出 `probe_status_file_passed_loopback_passed`；名称中的 `failed` 表示对应检查失败。不需要让对话模型调用工具才能看到这项结果。
5. 如需实时复查，在支持该应用的对话中调用 `local_mcp_probe`。若设置页列出了工具，而模型报告未接入 MCP，保留这个现象，分别记录配置侧工具发现和对话侧工具调用状态。
6. 记录结果、Gemini 版本及所用的沙盒设置。保持准备终端运行，重启 Gemini 后重新连接，确认授权能保留。连接结果工具表示本次进程启动时的快照，实时复查不改变已列出的名称。

实时复查的成功结果：

```json
{"file":{"code":"ok","state":"passed"},"loopback":{"code":"ok","state":"passed"}}
```

两项分别检查，文件失败也会继续检查网络。探针同时把同样的脱敏结果写入标准错误，便于从客户端运行日志获取；标准输出只承载 MCP 协议。

## 3. 检查最小目录授权

需要验证目录隔离时，再开一个终端，用另一个新测试目录运行同一准备脚本，得到第二条诊断命令。只允许 Gemini 访问第一个目录，不授权第二个目录，然后分别运行两条命令。

预期第一个文件检查通过，第二个文件检查报告 `file_unavailable`，两条命令的网络检查均通过。仅使用这两个合成目录做对照，不选择真实凭据或其他用户文件。若客户端只提供整体放行而没有目录级授权，记录实际设置，交由实现阶段评估。

## 4. 如何判断结果

| 检查结果 | 处理 |
| --- | --- |
| 两项 `passed` | 文件与回环 HTTP 的基本通道可用；继续进行重启和最小目录授权验证。 |
| `file_unavailable` | 检查测试文件是否存在，以及 Gemini 是否允许子进程读取该目录。 |
| `file_marker_mismatch` | 文件不是本探针生成的标记，重新使用新目录准备测试。 |
| `network_error_-1004` | 无法建立连接；检查准备终端是否仍在运行、是否使用当前打印的端口和网络授权。 |
| `network_error_-1001` | 网络请求超时；保留沙盒设置与相关拒绝日志。 |
| `network_response_mismatch` | 端口或响应内容与本次 HTTP 探针不匹配，重新核对命令。 |
| 无法初始化或没有工具列表 | 收集客户端的启动/握手错误；这属于 stdio 启动阶段，不是文件或 HTTP 检查结果。 |

错误报告不包含测试文件内容、文件路径、地址或原始系统错误文本。请求限制为精确的本机诊断 URL，禁止重定向、代理、Cookie 与缓存；HTTP 检查期限为 5 秒。

## 5. 完成测试

在准备终端按 Ctrl-C 停止服务，并在 Gemini 中删除本次诊断关联应用及临时目录授权。将上述结果反馈给开发者，再决定后续本地配对实现。构建产物仅用于诊断时，无需替换正在使用的 Bridge App。
