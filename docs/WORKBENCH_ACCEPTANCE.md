# 工作台人工验收清单

使用已安装的 Release 应用验收。系统文件面板、授权窗口、鼠标键盘、输入法和视觉体验由使用者实际操作。使用测试项目验证文件与终端能力。

## 首次使用

- [ ] 打开应用后进入工作台，导航和输入草稿先可用，模型、历史各自显示加载进度。
- [ ] 未选项目时登录 ChatGPT，完成后自动读取模型，回到原输入位置。
- [ ] 添加自定义 API，读取模型；手填模型、推理强度、默认模型在再次获取目录后仍保留。
- [ ] ChatGPT 和两个 API 同时出现在模型选择器；同名模型按来源区分，添加连接保留已有连接。
- [ ] 从“更多模型连接”进入智谱 / Z.AI 与 WorkBuddy 设置，原有 ChatGPT 和自定义 API 连接继续可用。
- [ ] 智谱 / Z.AI 登录后按平台和套餐显示模型、连接状态与额度；Coding Plan API Key 的密钥输入提交后清空，Start Plan 提供网页登录。
- [ ] WorkBuddy 国内版和国际版可登录并选择模型；账号启停、刷新、签到与模型筛选显示结果，重启后恢复连接。国际版账号显示其支持的操作。
- [ ] 不选择文件夹发送普通消息。用户消息靠右，回复靠左；首次受理后侧栏立即出现会话并自动生成标题。
- [ ] 首次请求本地文件、终端或项目 Agent 时，显示一次目录选择。选择前工具未执行，选择后接续原请求，正文与标题连续。
- [ ] 取消目录选择后保留对话和原输入，其余普通聊天可以继续。
- [ ] Codex 位于 Agent 设置；外部 Agent 的连接、认证、模型目录各自显示状态和处理入口。
- [ ] 网页客户端按所选接入方式配置。首次实际成功调用后显示对应通路的成功状态；Gemini 接入方式重开后保持。

## 日常工作

- [ ] 主侧栏同时显示无项目聊天、项目会话和最近对话。切换全局项目只影响之后的新对话。
- [ ] 每个会话恢复自己的 Provider、模型、推理强度、权限、草稿和阅读位置。
- [ ] 输入框左下为权限与附件，右下为模型、强度和发送。状态位高度固定，长状态能展开查看完整内容。
- [ ] 顶部与底部边缘过渡自然，工具栏与设置入口统一；鼠标选择反馈克制，键盘焦点清晰。
- [ ] 发送、保存、连接和停止立即显示局部进度；同一对象处理中避免重复操作，其他区域仍可使用。
- [ ] 系统选择、粘贴和拖入图片均显示预览，可逐项删除；超出 8 张或合计 8 MiB 时有明确反馈。
- [ ] 使用 `/` 选择并执行原生命令；绑定目录后用 `@` 分页引用文件，修改搜索不会显示旧结果。
- [ ] Markdown、代码、表格、思考摘要、工具参数及结果、计划、审批、问答、后台作业和压缩各自清晰呈现。
- [ ] Token、TPS、上下文和压缩统计随引擎数据更新；长内容可分块查看、复制和导出到系统选择的位置。
- [ ] 流式回复、分页、切换检查器和文件预览时，草稿、焦点及输入法组合文字保持正常。
- [ ] 运行时追加任务进入队列列表，实际派发后进入正式正文；编辑、移除和“中断当前任务并发送”含义清楚。
- [ ] 两个不同 Provider 的子智能体可并行执行、分别追加任务，过程与结果回到原会话；单独停止只影响所选子项。
- [ ] 搜索覆盖授权范围内的工作台、Bridge 任务和支持目录的 Agent 历史，分页不重复，可打开并定位匹配消息。
- [ ] 网页工作台可插入对话、续写、重试和交接，沿用原配置与附件，结果归属原会话。
- [ ] 技能、MCP 和插件显示已保存、已生效、等待重启或失败；安装切换页面仍保留进度。

## 异常恢复

- [ ] 回复等待超过 10 秒后显示自动核对，编辑器保持稳定；恢复使用原操作 ID，正文没有重复用户消息。
- [ ] 提交后关闭窗口再打开，恢复原会话、草稿、附件和执行状态。
- [ ] 断网时仍可读取本地历史和草稿；恢复连接后接回原执行。
- [ ] 在目录绑定或任务停止期间重启后台，历史仍是一条会话，旧请求不会作为新任务重复发送。
- [ ] 停止根任务后，其活动子任务及进程完成收尾才显示终态；其他写任务在执行组释放后继续。
- [ ] 取消过的旧请求出现迟到回执时，之后的新任务继续正常运行。
- [ ] 项目文件夹被移动或失效后，已保存历史仍可读取，本地执行显示对应目录问题。
- [ ] 模型目录刷新失败时，已有连接、手填模型和已保存设置仍可查看；失败提示位于对应连接。
- [ ] 插件安装失败显示真实阶段与处理入口，未知回执保持核对状态。

## 后台运行与升级

- [ ] 切换页面、最小化和关闭窗口后，后台执行继续。
- [ ] 开启后台开关后退出应用，后台继续；关闭开关后退出，先保存状态并结束所属执行。
- [ ] 提醒表单可预览下一次触发时间。停用只影响未来触发，已生成任务可独立停止。
- [ ] 重开提醒从下一次计划开始；错过执行由使用者选择补做，修改规则影响之后的触发。
- [ ] 更新等待列出阻塞任务，能打开对应会话，空闲后自动继续，也可取消等待。
- [ ] 覆盖安装后保留现有历史、设置、应用数据和网页登录状态；旧 ACP 与外部桌面会话沿用原绑定。
- [ ] 在干净环境安装后，直接使用包内运行时；无需另外安装 Node、包管理器或引擎。
